## 0. 结论

1.1.0 要突出**两件独立的事**，界面上也分成两块：

| | 分流规则 | 配置模板 |
| --- | --- | --- |
| 回答的问题 | "我想维护一份自己的规则，并拿到订阅链接" | "我想要一份能直接导入客户端的完整配置" |
| 来源 | **1.0.x 已有能力，体验恢复到 1.0.7** | **1.1.0 新增** |
| 产物 | 规则订阅链接（YAML / LIST / TXT / JSON） | 配置订阅链接（mihomo / Surge / sing-box 等完整配置） |
| 用户需要知道 | 想放哪些网站 / IP | 用什么客户端、机场订阅、想让哪些服务单独分流 |
| 依赖关系 | 不依赖模板，可单独使用 | 可以**引用**分流规则，也可以完全不用 |

关系是单向的：**规则 → 模板**。只用 1.0.x 功能的用户，打开 1.1.0 后应当感觉"还是原来那个工具，多了一个模板入口"。

## 1. 现状问题（beta.1 对照 1.0.7）

| 方面 | 1.0.7 | beta.1 | 问题 |
| --- | --- | --- | --- |
| 导航 | 概览 / 规则 / 订阅 / 设置 / 关于 | 概览 / 规则集 / 规则目录 / 应用组件 / 模板 / 发布 / 设置 | 7 个入口平铺，规则与模板两条线混在一起；模板的内部概念（目录、组件、发布）各占一个入口 |

| 新建规则 | 先选起点：从零构建（自定义规则）/ 上游订阅 / Geo 数据库，Geo 支持关键词搜索（"telegram、ai、netflix"），首次创建自动同步 | 规则集表单 + 来源面板分开操作 | 失去"选起点"的引导 |

| 模板 | 无 | 起步模板 → 画布 → 槽位 → 发布（另一页）→ 选 full/minimal → 绑定订阅 | 一份配置要跨 3 个页面、理解 6 个概念；未配置 `SESSION_SECRET` 时绑定被禁用 |

## 3. 分流规则模块（恢复 1.0.7 体验）

原则：**交互流程以 1.0.7 为准，保留 beta.1 的后端修复与体验改进**（批量导入预览、冲突检测、搜索、同步状态）。实施前（M0）逐页对照 1.0.7 实际运行截图，列出每一处差异再改。

### 3.0 M0 对照结论（以 1.0.7 实际界面为准）

基准截图：`.baseline/1.0.7/`（1.0.7 运行截图，桌面 1440 与手机 390），`.baseline/beta.1/`（同数据下的 beta.1）。基准源码：`git show 5cb9012:src/frontend/components/<file>.tsx`。

| B4 | `SESSION_SECRET` | 【待定 D2】见下 |

**B4**：当前未显式配置 `SESSION_SECRET` 时节点绑定被禁用，新建模板第 3 步会卡住。

- 方案 A（推荐）：Docker 首次启动若未配置，自动生成随机密钥写入数据卷 `/data/.session-secret`（0600），日志提示备份时一并备份；Workers 部署在第 3 步显示一次性引导（附 `wrangler secret put SESSION_SECRET` 命令）。代价：放宽 beta.1"不回退库内密钥"的决定，数据卷整体泄露时节点地址不再受保护。
- 方案 B：保持现状，第 3 步改为白话引导 + 允许"暂时不填"继续生成。

### 9.1 M3.5 动效统一（用户 2026-11-27 追加并确认按此规范执行；收尾阶段、M4 之前）

背景：1.0.7 动效丰富但各自为政（登录退出 blur + scale 0.6–0.9s、菜单弹入、规则行状态切换、批量操作底栏、按钮按压缩放；时长 180–920ms、多种曲线并存，观感割裂）；beta.1 几乎只剩 `transition-colors`，显得生硬。目标：**恢复全局交互动效，但用一套统一的动效规范**，不照搬 1.0.7 的具体实现。

| 项目 | 规范 |
| --- | --- |
| 动效 token | 时长三档：`--motion-fast` 120ms（按压、颜色）、`--motion-base` 200ms（悬停、展开、弹层）、`--motion-slow` 320ms（页面与大面积进出）；曲线统一 `cubic-bezier(.16,1,.3,1)`，退出用 `cubic-bezier(.4,0,1,1)`；定义在 `tokens.css`，组件只引用 token |
| 按钮 / 卡片 | 悬停：轻微上浮或阴影加深；按下：`scale(.97)`；禁用无动效；全局 Button、可点击卡片、底栏导航统一 |
| 弹层 | 对话框、抽屉、下拉菜单、tooltip、toast 统一"淡入 + 轻微位移/缩放"进入、更快退出 |
| 列表 | 规则启用/停用、批量模式进入退出、新增与删除行有短过渡；折叠区展开高度过渡 |
| 页面 | 路由切换仅 ≤200ms 淡入，不使用 blur，不阻塞内容（保持现有 SPA 跳转 <200ms 的 e2e 预算） |
| 登录 | 保留"登录后进入控制台"的衔接动效，但总时长 ≤400ms、无 blur |
| 无障碍 | `prefers-reduced-motion: reduce` 时全部降为无位移的瞬时或淡入 |
| 验收 | 所有动效只用 transform / opacity（不触发布局）；e2e 性能预算不变；桌面与手机录屏各一份给用户确认 |
