# 1.0.x → 1.1.0 前端功能核对清单（M3.3 切换门禁）

## 3. 旧前端清理与测试迁移说明

- **删除的旧前端代码与静态资源**：
  - `src/frontend/**`（全部 30 个旧前端组件、样式、脚本及 2.5MB 旧 PNG 图片；运行期 `opencc-js/cn2t` 1.09MB 分包随之彻底移除，`opencc-js` 仅保留在 `devDependencies` 供构建期脚本使用）。
  - `preview.html`（过渡预览入口已由 `index.html` + `/admin` 正式入口替代，`/preview/*` 由服务端 302 重定向至 `/admin/*`）。
- **测试迁移说明**：
  - `tests/unit/i18n.test.ts`（删除）：仅测旧版 `src/frontend/i18n.tsx` 运行期文本翻译函数；其覆盖的英文零中文残留、繁中术语校验与系统语言解析已由 `tests/unit/web-i18n-and-assets.test.ts` 完整替代。
  - `tests/integration/app.test.ts`：从校验 `/preview` 返回 `preview.html` 更新为校验 `/admin`、`/admin/*`、`/pwa-install` 返回正式入口，且 `/preview` / `/preview/*` 302 重定向至 `/admin` / `/admin/*`。
  - `tests/e2e/auth.spec.ts`：保留原 4 条核心场景（登录/刷新/登出、未知 API 404、免鉴权 `/pwa-install` 与 PWA 资产、Telegram Mini App 深度链接与写权限），选择器切换为新前端正式 `/admin` 语义。
  - `tests/e2e/compatibility.spec.ts`：从依赖旧版 `.subscription-format-group` / `.bulk-card` DOM 结构的断言，升级为覆盖本清单全部核心条目（1.0.x `?view=` 深度链接、`/preview` 重定向、三语订阅格式含 YAML/Loon/QX/sing-box、小屏批量导入滚动、PWA 缓存策略、Mini App 权限与服务端 403 一致性）。
  - `tests/e2e/preview-*.spec.ts`：全部访问路径由 `/preview*` 切换至正式 `/admin*` 入口，三视口、1 万条规则分页与全流程测试继续保留运行。
  - 1.0.x 后端兼容别名（`/api/categories`、`/api/data`、`/api/rules?all=1`）与 1.0.x 订阅黄金比对测试（`tests/integration/migration.test.ts`）保持原样继续通过。
