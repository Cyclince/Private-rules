# 1.0.7 security and data-safety release

- Backup import now validates the whole file before changing anything and writes it in a single atomic batch. A malformed backup returns 400 with a list of problems instead of wiping existing rules.
- `/api/links` no longer returns `RULE_TOKEN` to API key callers, matching `/api/categories`.
- Admin login is rate limited: after 10 failed attempts within 15 minutes, further attempts from that client are refused for the rest of the window. A successful login clears the counter.
- Passwords, subscription tokens, and session signatures are compared in constant time.
- Rate limiting no longer trusts `X-Forwarded-For` unless `TRUST_PROXY=true`. The Node runtime uses the socket address; Cloudflare uses `CF-Connecting-IP`.
- Fixed `/admin` returning 500 on newer Node.js releases (`Illegal invocation` when cloning the request).

Docker images `cyclince/private-rules:1.0.7` and `cyclince/private-rules:latest` support `linux/amd64` and `linux/arm64`.
